# Discovery kit (blueprint sections 3.4 and 7)

**No interviews, surveys or usability tests have been conducted.** Everything here is a plan or a template. The personas, pain points, price points and payment assumptions in the blueprint remain **hypotheses** until they are tested with real people. Do not cite anything in this folder as evidence.

| File | Use |
|---|---|
| `interview-guides.md` | 45-minute scripts: learner, instructor, institute admin, corporate HR |
| `survey.md` | 10-question survey (English + Bangla), target 150+ responses |
| `usability-test-plan.md` | 5 learners on Android with `../prototype/index.html` |
| `consent-and-privacy.md` | Consent script and data handling rules |
| `synthesis-template.md` | How to turn notes into findings and decide hypotheses |
| `recruiting-tracker.csv` | Blank tracker, 18 rows |

Suggested order: recruit (tracker) -> 5 learner + 3 instructor + 2 admin + 2 HR interviews -> survey in parallel -> synthesis -> usability test on the prototype -> update the blueprint.
Decision rule: write down beforehand what result would make you change the plan (see synthesis template).
